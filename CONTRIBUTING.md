# Contributing to Ai2Psd_Pro

Thank you for your interest in contributing to **Ai2Psd_Pro**! We welcome ideas, bug reports, feature suggestions, and pull requests.

---

## 🛠️ How Can You Help?

1. **Reporting Bugs**:
   - Check existing [GitHub Issues](https://github.com/mujahidul80/Ai2Psd_Pro/issues) to avoid duplicates.
   - Provide your Adobe Illustrator version and operating system (e.g., Illustrator 2024 on Windows 11).
   - Attach screenshots or error dialog messages if available.

2. **Suggesting Enhancements**:
   - Open a feature request issue with a clear description of the workflow improvement.

3. **Submitting Pull Requests**:
   - Fork the repository.
   - Create a feature branch (`git checkout -b feature/amazing-feature`).
   - Commit your changes (`git commit -m 'Add amazing feature'`).
   - Push to your branch (`git push origin feature/amazing-feature`).
   - Open a Pull Request.

---

## 📜 Development Guidelines

- Scripts are written in **Adobe ExtendScript (JavaScript ECMAScript 3 / JSX)**.
- Ensure cross-version compatibility (CS6 through recent CC/2026+ versions).
- Test on both dark and light UI themes (`app.preferences.getRealPreference('uiBrightness')`).
